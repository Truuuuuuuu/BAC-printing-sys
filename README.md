<h1>BAC Management Printing System</h1>


<h3>About this project</h3>
<p>This system aims to assist government staff by partially automating the editing and printing of Bids and Awards Committee (BAC) documents, improving efficiency, accuracy, and consistency in document preparation.</p>

<p>
This project was originally developed as a web application. By integrating the Tauri framework, it has been transformed into a self-contained desktop application that runs natively on Windows without requiring a separate web server installation.
</p>
